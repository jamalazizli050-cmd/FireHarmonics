# Earth textures — provenance and licence

| File | Content | Source | Licence |
| --- | --- | --- | --- |
| `earth-blue-marble.jpg` | Blue Marble surface imagery | NASA Visible Earth "Blue Marble", redistributed in the `three-globe` example assets (`three-globe@2.45.6/example/img/`) | NASA imagery is public domain (not subject to copyright in the US); `three-globe` example files are distributed under the MIT licence |
| `earth-topology.png` | Elevation bump map | NASA (via `three-globe@2.45.6/example/img/`) | Public domain / MIT as above |
| `earth-water.png` | Water mask (specular map) | NASA (via `three-globe@2.45.6/example/img/`) | Public domain / MIT as above |

Country borders come from Natural Earth 1:110m admin-0 (public domain) via the `world-atlas@2.0.2` npm package (ISC).

The Figma Community globe (https://www.figma.com/community/file/1611332293521806958) was **not** used: its licence
could not be verified (HTTP 403 to automated access) and the Figma MCP only accepts `/design/` file keys, not Community
file IDs. The 3D Earth is an original implementation with the openly licensed data above.
